  ═══ 8. 教学洞察 ═══

  1. 选卡质量决定一切（精准 vs 错配）
     精准: 12982万 → 错配: -470万
     差距来自: 转化率(274倍) × 单台利润(¥4682 vs ¥-50691)
     → "选对功能比选多功能重要"

  2. 产品好 → 可以卖更贵（γ 机制）
     精准γ=2.47 → 定价76% WTP
     错配γ=3.99 → 定价62% WTP
     → "好产品的溢价来自消费者信任, 不是定价策略"

  3. 堆料≠好产品（堆料 vs 精准）
     堆料dCOGS=¥1400 (精准的2.1倍)
     堆料利润=298万 (精准的2%)
     → "花了2倍的钱, 利润反而只有精准的2%"

  4. B/C 端差异来自市场结构, 不是产品
     ToC: f=0.25, Meff=2.1M → 12982万
     ToB: f=0.15, Meff=1.2M → 10297万
     → "同样的产品, 渠道和市场选择决定了利润天花板"

  5. 错配队伍的死亡螺旋
     转化率低(0.004%) → 量少(93台) → F摊不薄 → 单台成本¥58601
     → "不是定价错了, 是没人想买你的产品"
