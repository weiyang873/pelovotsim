# VP Coach V5b 模拟对话 — 判据驱动的教练模式

## Coach 内部检查表（不展示给学生）

### C（任务普遍性）
- C1：任务是否高频
- C2：任务是否面向可识别购买单元
- C3：场景是否非偶发

### G（可泛化度）
- G1：是否不依赖单一极端触发事件
- G2：是否能迁移到同类用户
- G3：收益是否不仅对少数高敏感用户成立

### E（价值创造说服力）
- E1：机制是否清楚
- E2：是否有替代方案对比
- E3：是否说明边界条件

## Coach 行为模式

```
听 → 标记（哪几条被触及）→ 深化亮点（顺着学生说的好的地方追）→ 探缺口（一次只补一条）→ 循环
```

## 样本 A：ToC · 差异化 · 儿童 · 体验型

**设定**
- 团队 4 人
- 锦囊：内容营销、母婴KOL矩阵、情感计算算法、儿童安全交互认证

### 【Coach 开场】

你们选的是消费者·差异化·儿童，定位体验型。

接下来要写价值主张。价值主张就是一句话：**你的产品为客户创造了什么价值？**

怎么想？三步：

**客户任务**——你们选的这个市场里的人，每天在忙什么、要做到什么？不是"他们是谁"，而是"他们要完成什么事"。任务越普遍，市场越大。

**痛点**——完成这个任务时，什么地方卡住了？要有具体场景。"孤独"不是痛点，"孩子放学回来带着情绪但没人接得住"才是。

**价值创造**——LOVOT介入之后，客户的处境发生了什么变化？不是LOVOT有什么功能，而是客户得到了什么以前得不到的东西。要说清楚为什么现有替代方案做不到。

请团队讨论2-3分钟，写出第一版，不需要完美。

（234字）

## 样本 B：ToB · 成本 · 老人 · 功能型

**设定**
- 团队 3 人

## 教练行为模式总结

### 核心循环

```
学生发言 → Coach 内部标记9条判据 → 找到已触及的亮点 → 深化（"这句话好因为___"）→ 找到最关键的未触及缺口 → 用一个问题探（一次只探一个）→ 学生回应 → 循环
```

### 与 V4 线性追问的区别

| V4 | V5b |
|----|-----|
| 固定顺序：WHO→PAIN→HOW | 跟着学生走，哪条先说就先深化哪条 |
| 每轮追问一个要素 | 每轮先肯定亮点再探一个缺口 |
| Coach主导节奏 | 学生的表述决定节奏 |
| 反馈笼统（"再具体一点"） | 反馈锚定判据（"你们的任务频率还没说清楚"） |
| 开场列启发角度 | 开场只讲框架，不给方向 |

### Coach 什么时候进入整合
- 9条判据中至少6-7条被触及（C/G/E各至少2条）
- 或对话已到第5-6轮
- 两个条件满足其一即可整合并引导评分

### 评分时的判据对应
- 评分反馈直接对应判据：C=4.2是因为C1✓C2✓C3✓
- 提分建议指向具体缺口：到4.5需要补哪一条
- 不说"再具体一点"这种笼统话
