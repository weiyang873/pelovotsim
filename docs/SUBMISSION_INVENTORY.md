- 模型：deepseek-v4-flash（`LLM_DISABLE_THINKING=1`），temperature：R1/R2 0.55，小传写手 0.9，编码器 0.1–0.2；并发 3–6；重试 3–8 次 + 机械检查（长度/禁用词/schema）——见 presets 与生成器源码。

- 信息防火墙、任务盲生成、20 字段目录、8 维 IID 特质——PERSONA_METHODS §2；pool_manifest.json 的 sha。
- 信息集对齐（只看得见真页面信息、分页不拼页）——docs/CODEX_INFO_SET_ALIGNMENT.md §1.5。
- 随机性与复现：seed 只保证抽样/调度可复现，LLM 输出不保证（run_meta.seed_reproducibility_note）；重测 ICC≈0.3（FREEZE_LEDGER Reliability）。
- 成本：按批次调用数 × DeepSeek 价目（需从 biography_calls / actor_calls jsonl 统计 token，待补）。
- 人工与 GenAI 分工：设计决定（WY）；代码/探针/分析（Claude Code + Codex）；编码与回测由 LLM 担任评审并在文中标明局限。
