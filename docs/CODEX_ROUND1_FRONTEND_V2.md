# CODEX_ROUND1_FRONTEND_V2.md

## 目标

对 Round 1 多人模式前端进行全面改进，涵盖 6 个步骤页面的引导文案、交互逻辑和信息展示。核心原则：让学生看界面就能做出选择，不暴露引擎内部逻辑，不出现公式/参数符号。

参考原型文件：`round1_prototype_v2.jsx`（附件）

### 标题和说明

- 标题：`🎯 你的个人锦囊`
- 说明：`每位成员获得 2 张锦囊（1 市场能力 + 1 技术能力），描述了你在某些方面的独特能力。`

### 提示框

黄色背景卡片，标题 `💡 怎么用锦囊？`，内容分两段：

1. `锦囊描述了你在某些方面的独特能力。小组所有成员的锦囊都会在最终结算时生效——关键是团队选择的市场定位和价值主张能否"击中"这些能力。匹配度越高，团队在成本或市场份额上的优势越大。`
2. 分隔线后：`🧭 锦囊能力不是必须使用的——你也可以根据案例材料和课堂讨论，对市场方向做出自主判断。`

### 阅读引导

卡片上方斜体文字：`仔细读一读每张卡描述的能力——想想它们和哪些市场方向最契合。`

- 翻牌前：按钮灰色不可点，文案 `请先翻开两张锦囊`

## Step 2：选战略

### 标题和说明

- 标题：`🎯 选择你的战略定位`
- 说明：`根据你的锦囊能力和对市场的判断，在下方地图上点击你认为最有机会的目标市场。`
- 灰色小字：`这是你的个人初选——之后小组会看到所有人的选择，再一起讨论收敛。`

### 锦囊提示

在地图上方显示当前成员的两张锦囊（mini 模式，只显示 icon + 标题）。

### 策略解释

地图上方两个并排卡片解释差异化和成本领先：

- **差异化**：`靠独特体验或功能赢得用户，可以定更高的价格，但目标人群更窄`
- **成本领先**：`靠性价比和规模赢得用户，价格敏感但人群基数更大`

### 市场地图

标准 12 格地图（2×2×3），点击选中高亮。

### 产品定位方向（原"架构标签"）

标题直接用问题形式：**`你希望 LOVOT 在这个市场中主要靠什么打动用户？`**

三个可选按钮卡片，选中时高亮边框+背景色：

| 选项 | 描述 | 示例 |
|---|---|---|
| 体验型 ● | 用户买的是情感价值和陪伴体验，功能够用就行 | 例：老人每天和 LOVOT 说话解闷；孩子把它当宠物养 |
| 混合型 ▲ | 体验和功能都是卖点，缺一不可 | 例：既能陪伴老人，又能检测跌倒并通知家属 |
| 功能型 ■ | 用户买的是实用功能，情感体验是锦上添花 | 例：企业采购用于前台接待和导览；学校用于编程教育 |

### 价值主张草稿

- 标签：`一句话价值主张草稿（选填）`
- 提示：`尝试回答：给谁（WHO）、解决什么问题（PAIN）、怎么解决（HOW）`

### 提交按钮

必须**同时**选择了目标市场和产品定位方向才可提交。否则灰色，文案动态提示缺什么：
- 都没选：`请选择目标市场并选择产品定位方向`
- 只选了市场：`请选择产品定位方向`
- 只选了定位：`请选择目标市场`
- 都选了：`提交我的选择 →`

- 标题：`📊 小组战略分布`
- 说明：`所有人的选择已揭晓。观察你们的共识和分歧，讨论后在下方确定团队的统一方向。`

### 分布地图

显示所有成员选择的地图（每人一个彩色圆圈）。

### 成员图例

每个成员显示：彩色头像 + 姓名 + 选择的市场 + 该成员的两张锦囊（mini 模式）。

### 锦囊动态亮灯

当团队在下方"确定小组最终选择"中选了某个市场时，成员锦囊卡自动更新高亮状态：
- 与所选市场匹配的锦囊：显示 `✦ 匹配` 标记 + 边框高亮 + 阴影
- 不匹配的：普通样式

匹配逻辑：根据锦囊 affinity 字段与 cellKey（`{customer}_{strategy}_{age}`）比对，所有 affinity 属性都不冲突且至少一个匹配即为命中。

### 锦囊匹配分析面板

绿色背景面板，标题 `🔦 锦囊匹配分析`：
- 文案：`如果团队选择 [当前选中的方向]：`

- 底部统计：`X 张锦囊可激活`

### 分布洞察

黄色面板，标题 `📌 分布洞察`，AI 生成的文字描述分布特征和核心分歧（示例：`3/4 的成员选择了差异化策略...需要讨论的核心分歧：ToC 成人 vs ToB 老人`）。

带边框的独立区块，标题 `✅ 确定小组最终选择`，说明 `讨论完成后，在这里确认团队的统一方向。这个选择将作为后续撰写价值主张的基础。`

包含：
1. **团队目标市场**：一个完整的 12 格地图，可点选（选中显示 ✓ 绿色方形标记，区别于个人圆形头像）
2. **团队产品定位方向**：三个按钮（体验型 ● / 混合型 ▲ / 功能型 ■），可选中高亮

### 提交按钮

必须同时选了团队市场和产品定位才可进入下一步。
- 未完成：灰色，`请先确定团队的目标市场和产品定位`

## Step 5：结果展示

### 设计原则

- **不暴露公式和参数符号**：不出现 SAM、WTP、λ、ρ(C)、E_adj、GMmax 等
- **不出现精确数字**：不显示亿元数值、绝对价格
- **定性档位 + 自然语言反馈**：市场空间用小/中/大，支付意愿用相对百分比
- **锦囊匹配用匹配强度标签**（高/中），不标注"本轮生效/下轮生效"

### 结构（从上到下）

#### 1. 战略选择横幅

深绿色渐变横幅：
- 小标题：`你们的战略选择`
- 大标题：`企业 (ToB) · 差异化 · 老人 · 体验型`
- 价值主张全文

#### 2. 市场空间

三档高亮选择器（小 / **中** / 大），当前档位用深绿实色标记。下方一段自然语言解读该市场特征。

后端计算：由 `SpaceScore = BaseSize × g(etier) × h(crowding) × m(reach)` 映射到 S/M/L 档位。前端只显示档位和文字解读。

#### 3. 用户支付意愿

横向卡片展示：
- 左侧标签：`用户支付意愿` + `相对于该细分市场平均水平`
- 中间大字：`+X%`（绿色正值 / 红色负值）
- 右侧一句话解读

后端计算：`WTPadj / WTPref - 1` 转为百分比。其中 `WTPadj = WTPref × λ(G) × λ(Eadj)`。前端只显示百分比和文字解读，不暴露乘子。

#### 4. 价值主张评分

三个维度，每个显示：
- 中文标签 + 英文缩写：`人群覆盖面 (C)`、`痛点普遍性 (G)`、`解法说服力 (E)`
- 右对齐分数：`X / 5`
- 5 格进度条（彩色填充到对应分数）
- 下方一句话文字反馈（来自 LLM 评分时的 feedback 字段）

#### 5. 锦囊匹配结果

绿色面板，标题 `🎯 锦囊匹配结果`：
- 统计文案：`团队共 N 张锦囊中，X 张与当前定位匹配`
- 每张匹配的锦囊显示为独立卡片：icon + 标题 + 匹配强度标签（高匹配/中匹配）+ 效果描述（自然语言）
- 底部说明：`所有团队成员的锦囊（包括未匹配的）都会带入第二轮计算。未匹配的锦囊在不同的产品能力选择中仍可能发挥作用。`

匹配强度标签基于 `match_strength` 连续值：
- `m >= 0.7` → 高匹配（深绿标签）
- `0.3 <= m < 0.7` → 中匹配（浅绿标签）
- `m < 0.3` → 不展示

效果描述（由后端根据锦囊类型生成）：
- 市场锦囊：`→ 提升了价值主张的可信度`
- 技术锦囊：`→ 选择相关能力卡时成本更低`

#### 6. 第一轮完成（回到课堂）

深色底部面板：
- 标题：`🎉 第一轮决策完成`
- 文案：`你们已经完成了产品战略制定。请先放下手机/电脑，回到课堂参与集体讨论。`
- 灰色卡片说明接下来的课堂环节：`老师将带领大家回顾各组的战略选择，讨论不同方向的优劣势。之后再进入第二轮：产品研发决策。`
- 底部居中灰字：`第二轮将由老师统一开启`
- **不提供"进入第二轮"按钮**

### market_space_narrative 和 wtp_narrative 的生成

这两个字段可以由后端根据格子参数模板化生成（不需要 LLM），例如：

- ToB + DIFF → `机构客户数量有限，但单笔采购量较大。差异化策略下客户支付意愿较高，不过需要较长的销售周期来建立信任。`
- ToC + COST → `消费者市场基数大，但价格敏感度高。需要靠性价比和口碑传播快速起量。`
