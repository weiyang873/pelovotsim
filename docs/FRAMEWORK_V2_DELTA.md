# FRAMEWORK_V2_DELTA

## 10.1 选卡规则

- 6 维度，每维度 3-5 张能力卡，每卡分高/中/低三档
- 每维度至少选 1 张
- 无数量上限
- 经济学自约束：每多选一张卡增加 dCOGS（单台变动成本）和 NRE（固定研发投入）
- 选卡过多会导致毛利下降、NRE 上升、BEQ 急剧攀升，小市场无法回本
- 跨维度兼容性约束（hard rules + soft penalties）
- 技术锦囊：match_strength 高的锦囊降低对应卡的 risk / dCOGS / 提升 performance

## 19.2 渐进揭示的教学意图

取消选卡上限后，渐进揭示更重要：

- 选卡时看不到数字，学生更容易贪心多选
- 合并时揭示 dCOGS 和 NRE，制造“选太多会发生什么”的冲击感
- 讨论阶段再揭示 F_total 和 BEQ，迫使团队做取舍
- 结果页最后揭示销量和利润，完成复盘闭环

核心教学点：

- 约束不是老师定的规则
- 约束来自市场和成本结构本身
