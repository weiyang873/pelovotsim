## 2. 判决指标（第一批可报均值±区间的正式读数）

1. **盈利率与利润**：按条件 × 双口径（含/除体制转型者）报均值与区间；Q vs S 差值（同 run 配对）
2. **价格**：逐 persona Q×3 vs S×3 均值——降价方向的正式存活率
3. **问题稳定性**：Q 臂 63 问按 persona 分组交付 question_list；体制政策轴、各人签名轴复发计数
4. **IMP 已移除后的需求感知**：IMP 表已不在 UI——观察 persona 是否转而依赖 D3 访谈洞察做维度优先级（理由文本溯源），以及 tier 分布与其 D3 证据的对应关系（承接 infoset_v3 指标但换了信息前提，明确标注不与上轮 IMP 响应率直接对比）
5. **格子稳定性矩阵**：每人 6 条链的格子选择
6. **链内一致性抽样**：每 persona 取 1 条 Q 链，问题→选卡→定价自洽性引原文短评
7. **嵌入数字的使用分化（新 UI 专属新指标）**：谁在理由/问题中引用了卡面万元数字并做了计算、谁完全无视——"给了锚但不一定人人捕捉"是 WY 本次 UI 改动的设计意图，捕捉率的人格分布是第一批读数
8. 局限声明：N=3、锦囊单套、solo、单基座、新 UI 口径下无历史同口径对照
