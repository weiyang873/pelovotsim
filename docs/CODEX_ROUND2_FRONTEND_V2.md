# CODEX_ROUND2_FRONTEND_V2.md

## 目标

对 Round 2 多人模式前端进行全面改版。

参考原型：`docs/round2_prototype_v2.jsx`（以此为准，本文档是补充说明）

---

## 全局变更

### 步骤：6 步

```
第一轮回顾 → 用户访谈 → 个人选卡 → 团队合并 → 研发与定价 → 确认提交
```

注意：维度分配不再是独立步骤（课堂模式下系统自动分配）。定价合并到"研发与定价"步骤中。最后一步是确认总结页+结果页，提交后展示销量与利润拆解。

### 术语替换

| 旧 | 新 |
|---|---|
| Round 2 标题 | Round 2 · 第二轮决策：产品研发 |
| LOVOT（卡片描述中） | AI机器人 |
| VP | 价值主张 |
| 系统负载 / 负载 X | 移除，不展示 |
| 增量成本 +120 | 个人阶段→"成本：中"；团队阶段→"+120元" |
| 风险-高 | 风险：高 + 每张卡有具体风险说明（riskNote 字段） |
| 雷达 7.5 | "用户需求：高/中/低" |
| 预算 546 元 | 移除，改用毛利率档位（健康/良好/偏紧/危险） |

### 全局隐藏项（不展示给学生）

- 系统负载数字（load）
- 订阅贡献数字（sub_lift）
- 毛利率百分比数字（只显示档位）
- target_gm / Pmax / COGSbase 等引擎参数
- 锦囊内部编码（T01-30%）
- WTP 绝对值或范围（会导致锚定）
- 购买意愿/利润空间的档位标签（会导致学生沿边界卡价）

### 毛利率计算（前端展示用）

```javascript
// 真实公式，参数来自框架文档 §12.2, §11.3
const V = 4200;          // 变动成本/台
const f = 0.15;          // ToB 渠道费率（ToC 为 0.25，根据格子动态取）
const GM = (P * (1-f) - V - dCOGS) / P * 100;
```

不再使用固定预算线（BUDGET）。毛利率是唯一的成本健康指标：
- ≥40%：健康
- 30-40%：良好
- 20-30%：偏紧
- <20%：危险

## Step 0：第一轮回顾

### 结构（从上到下）

1. **任务背景框**（灰色底）
   - 标题："📋 决策任务回顾：AI 硬件中国市场的创新战略"
   - 正文："LOVOT 是一款 AI 机器人，你们的团队正在为它寻找中国市场的最佳定位，并基于这个定位进行产品创新改造。"

2. **第一轮决策回顾**
   - 战略方向横幅（深绿色底）：格子 + 架构
   - 价值主张展示（叙事格式）：给谁 / 解决什么 / 怎么解决（从 VP Coach 的 WHO/PAIN/HOW 读取）

3. **第二轮预告**（深色底）
   - 标题："第二轮：基于定位的产品创新"
   - "战略方向已经定了，现在的问题是：产品到底做成什么样？"
   - 三步卡片：挖掘需求 → 技术决策 → 定价与结果

### 不出现的
target_gm、Pmax、COGSbase、渠道费率、BUD 公式、锦囊契合度数字、市场空间档位、WTP 相对百分比

## Step 1：用户访谈

### 访谈规则（显示给学生）
- 团队最多 **3 位成员**参与访谈
- 每人与一位 AI 模拟用户独立对话，最多 **10 轮**
- 系统评估信息收集完整度，充分时提示可结束

### 访谈 UI
- 顶栏：访谈对象名+年龄+身份 | 对话轮次 X/10
- 聊天区：气泡式对话（用户灰色靠左，学生绿色靠右）
- 底部：输入框 + 发送按钮
- 进度条：信息收集度（初步 → 基本 → 充分）

### 访谈结束后
- 显示 6 维度用户需求权重（高/中/低），不显示数字分数
- 生成文字摘要（3-5 句，从后端 `session.summary` 读取）

### 后端对接
- `POST /api/marketing/start`：传 teamKey + memberId，返回 persona 卡片
- `POST /api/marketing/interview`：每轮对话
- `POST /api/marketing/end-interview`：结束，返回 scores + summary
- `GET /api/marketing/team-summary`：合并所有成员结果

### Prototype 专用
保留成员切换器（黄色底，标注"⚙️ 演示用"），正式版去掉。

## Step 2：个人选卡

### 核心原则：不显示成本数字

### 页面结构

1. **标题 + 说明**
   - "为你负责的维度选择能力卡。把你认为产品应该具备的能力都选上，再选择合适的档次。"
   - 灰色小字解释成本和风险含义："每个档位标注了**成本**（研发和量产投入的大小）和**风险**（技术实现的不确定性——选高了可能做不出来或延期）。"

2. **Sticky 状态栏**：只显示"已选 X 张" + 提交按钮。不显示预算、成本、毛利率。

3. **🎙️ 访谈洞察卡**（绿色底）
   - 该成员的访谈文字摘要（从后端读取）
   - 该成员负责维度的用户需求权重标签

4. **维度选卡区**（只显示该成员负责的维度）

### 每张卡的结构

```
[□] 卡片名称
    一句话功能描述（what 字段）
    ⚠ 具体风险说明（riskNote 字段，不是笼统的高/中/低）
    
    ○ 基础  说明文字          成本：轻    风险：低
    ● 标准  说明文字          成本：中    风险：中
    ○ 旗舰  说明文字          成本：较重  风险：中高
```

档位选择：纵排列表（radio 样式），每档一行，显示标签+描述+成本标签+风险标签。

### 维度标题右侧
- 个人阶段：选了才显示"已选 X 张"
- 团队阶段：也只显示"已选 X 张"

### 依赖关系
自然语言："需要 隐私与信任保障 达到标准以上（其他成员负责）"

### 冲突
互斥卡（如视觉表达 vs 无屏降本）：变灰+虚线边框+"✕ 与已选能力卡冲突"

## Step 3：团队合并

### 核心：雷达图 + 按维度访谈洞察 + 毛利率状态

### 页面结构

1. **雷达图**：6 维度能力分布可视化（SVG 六边形）
2. **🎙️ 访谈洞察（按维度）**：6 个维度条，每条显示维度名+需求等级+综合洞察文字。从 `GET /api/marketing/team-summary` 读取合并后的 summaries。
3. **预估毛利率**：档位展示（健康/良好/偏紧/危险），不显示百分比数字。进度条可视化。下方灰色小字："基于所选细分市场的平均水平预估。最终实际毛利率还取决于集体讨论中的选卡调整和定价决策。"
4. **已选能力卡数**
5. 超标时红色警告："当前技术选择成本过高，毛利率已降至危险区间..."
6. 提示："接下来进入集体讨论，可以看到每张卡的具体成本"

### 不出现的
- 按维度的卡片清单和成本明细（留给下一步）
- 预算数字（546 元已删除）
- 毛利率百分比

## Step 4：研发与定价

### 核心：选卡调整 → 成本核算 → 市场参考 → 定价 → 提交

这是最复杂的步骤，包含五个区块。

### 区块 1：标题 + 可折叠战略背景

- 标题："研发与定价决策"
- 说明："全组一起审视产品的技术能力组合。每增加一项能力或提升档次，研发成本都会上升。你们需要在产品竞争力和成本可行性之间找到平衡。"
- `<details>` 折叠面板："📋 查看战略背景（定位·价值主张·访谈洞察·雷达图）"
  - 内含：战略定位横幅、VP 全文、按维度访谈洞察摘要（精简版）、雷达图

### 区块 2：Sticky 状态栏

- 预期毛利档位（健康/良好/偏紧/危险，不显示百分比）
- 已选 X 张
- 状态提示（纯文字指示，不是按钮）："✓ 选卡就绪，下方定价" 或 "⚠ 预期毛利过低"

### 区块 3：6 维度选卡区（可调整，带成本数字）

所有 6 个维度全部展示（不只是自己负责的）。每张卡的档位显示具体成本数字（+X元）和风险标签。可以取消选择、更换档位。

### 区块 4：📊 成本核算

三张卡并排：
- 基础制造成本 ¥4,200（固定）
- 研发增量成本 +¥X（随选卡实时变化）
- 单台总成本 ¥X

底部：按维度的成本拆分标签（如 💬+520 👁+680）

### 区块 5：📈 市场参考（第一轮结果）

两张卡：
- 市场空间（小/中/大）
- 价值主张对支付意愿的影响（+X%）

底部一句话："单台成本 ¥X 是你们的盈亏底线。渠道抽走 X% 后到手更少。定价越高单台利润越大但买的人越少——你们需要找到量和利润的最佳平衡。"

**不显示 WTP 绝对值或范围**（会导致锚定）。

### 区块 6：定价决策

**定价须知**（三条原则）：
1. 渠道成本：定价不等于到手收入。ToB 渠道抽成约 15%。
2. 量价权衡：价格越高每台赚得多但买的人少。
3. 产品力影响：好产品让用户不那么在意价格。

**价格滑块**：范围 ¥5,000–¥20,000，步长 ¥100

**渠道抽成实时显示**：一张卡显示"渠道抽成 X% 后，每台到手 ¥Y"，跟着滑块动。右边拆解售价和渠道费。

**不显示**购买意愿档位和利润空间档位（会导致学生沿边界卡价）。

### 提交按钮

在定价区块底部。校验条件：至少 6 张卡 + 毛利率 ≥ 20%。不满足时灰掉并显示原因。

---

## Step 5：确认提交

### 两个状态

**状态 A：确认页**（默认）

完整决策摘要：
- 战略定位横幅 + 价值主张
- 雷达图
- 产品能力组合清单（按维度列出每张卡+档位）
- 三张数字卡：单台总成本 / 定价 / 渠道抽成后到手
- ⚠ "提交后不可修改"警告
- 两个按钮并排："← 返回修改" 和 "确认提交 ✓"

**状态 B：提交成功**（点确认后）

- ✅ 图标
- "提交成功！你们的产品方案和定价已提交。"
- "请放下手机/电脑，回到课堂参与集体复盘。"
- 提交后展示销量、固定成本、变动成本和利润拆解
